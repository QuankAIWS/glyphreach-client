# Contributing

GlyphReach Client is publicly viewable proprietary software. It is **not** an open-source project and is not presently accepting unsolicited code, asset, design, story, or documentation contributions.

## Pull requests

Unsolicited pull requests may be closed without review. Do not submit code or other creative material unless the project owner has specifically invited that contribution and the ownership/licensing terms have been agreed in advance.

A public fork or pull request does not grant permission to use GlyphReach code or content outside the rights provided by GitHub's Terms of Service or a separate written agreement.

## Bug reports and feedback

Ordinary product feedback and non-sensitive bug reports may be submitted through project channels that the owner designates. Do not include secrets, private account information, exploit details, or other sensitive security information in a public issue or pull request.

## Invited contributions

Invited contributors may be required to execute a separate contributor agreement, copyright assignment, work-for-hire agreement where legally applicable, or other written IP arrangement before material is accepted.

Unless the project owner expressly agrees otherwise in writing, no submission should be assumed to transfer ownership or grant broader rights to GlyphReach.
