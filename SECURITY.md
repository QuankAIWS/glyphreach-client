# Security Policy

## Reporting

Do not publish suspected vulnerabilities, credentials, authentication bypasses, exploit chains, private infrastructure details, or other sensitive security findings in a public issue or pull request.

Use GitHub's private vulnerability reporting/security-advisory mechanism if it is enabled for this repository. If no private reporting channel is available, contact the project owner through an established private channel before disclosing technical details.

## Scope

The public client is not authoritative. Security-sensitive decisions must be validated by the private backend. Client-side checks are usability measures and must never be treated as the sole enforcement boundary for inventory, progression, combat, currency, quests, access control, or other authoritative game state.

No vulnerability bounty, safe-harbor program, or authorization to test production infrastructure is offered by this file. Testing beyond ordinary use requires explicit permission.
